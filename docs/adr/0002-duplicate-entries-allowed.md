# Duplicate Entries are allowed and never merged

Entering a Product that is already on the List creates a second Entry. It does not reuse, uncheck or merge into the existing one, and two concurrent adds both stay. We chose predictability over deduplication, which reference apps such as KitchenOwl and Mealie do. What you type is what appears, and one Member's add never silently rewrites another Member's Note. To avoid accidental duplicates, suggestions mark Products that are «уже в списке» instead.
