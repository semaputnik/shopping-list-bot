# The List is the only unit of sharing

The first spec modelled a household (a family) that owned the lists, the product catalog, the categories and the stores. We dropped it. Each List is shared on its own through a Share link, every Member of a List has equal rights, and product memory belongs to one List. This keeps onboarding to one tap on a link and lets one person share different lists with different people. The cost is that nothing is shared across lists: suggestions, and later stores, have to be scoped per List or per user, not per family.
